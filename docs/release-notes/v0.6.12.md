## Türkçe

- Başka bir klip kısaltıldığında kısa ve hızı değiştirilmiş kliplerin kareleri, işaretçileri ve elle bırakılan boşluklar korunur.
- Taşınmış proje, eski klasör hâlâ mevcutken de yeni klasördeki medya kopyasını kullanır.
- Analiz önbelleği iç içe sonuçları boyut hesabına dahil eder. Tek bir büyük sonuç bellek bütçesini aşamaz.
- Windows ses önizlemesinde, hız veya konum değiştirirken oynatıcının dosya sonuna sıçramasına yol açabilen yükleme sırası düzeltildi.
- Windows paketlemesinde başka bir programın ICU kitaplığının Qt'nin açılmasını engellemesi giderildi.

Windows üzerinde genel test kümesine ek olarak 2.520 yerel kesim kombinasyonu, gerçek FFmpeg çıktıları ve Shorts penceresi sınandı. Denetim betiği proje kökünden çalıştırılabilir.

```powershell
./scripts/media-audit/run-audit.ps1 -Project .
```

## English

Local cuts preserve untouched frames, markers and manual gaps across clip speeds. Moved projects prefer the media next to the project file. Nested analysis results count toward the cache budget. Windows audio playback handles asynchronous seeks and rate changes, and the Windows build excludes incompatible third-party ICU libraries that could prevent startup.

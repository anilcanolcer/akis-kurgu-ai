## Türkçe

**0.6.8 kuruluysa uygulamadaki “Güncellemeleri denetle” seçeneğini kullanabilirsiniz.** Windows kurucusu mevcut kurulumun üzerine kurulabilir.

- Taşınan medyayı yeniden bağlarken aynı adlı iki çekim artık karışmaz. Diğer dosyalar, taşınan klasörün içinde kendi alt klasörlerinde aranır. Bir dosya hiçbir zaman iki farklı kaynağa verilmez; ayırt edilemeyen çekim için ayrıca sorulur.
- Açık projedeki bir kaynak dosya aynı yolda başka bir videoyla değiştirildiğinde akıcı önizleme yeniden çizilir; eski görüntü kullanılmaz.
- Hızı değiştirilmiş kliplerde duraklatılmış önizleme ile dışa aktarma aynı kareyi gösterir. Klibi bölmek artık çıktıyı değiştirmez. 2× hızda kareler bir kare geriden geliyordu, 0,5× hızda son kare eksik kalıyordu; bunlar düzeltildi. 24 ve 60 fps videolarda bölme de çıktıyı artık değiştirmez.
- Sağdan kırpılan kelime kelime altyazıda kırpılan kelimeler artık görünmez; klip yeniden uzatılınca geri gelirler.
- Windows'un kabul ettiği uzun proje adlarıyla kayıt yapılabilir.
- Sürüm klasörüne elle konmuş dosyalar, eski sürümler temizlenirken silinmez.

Windows kurucusu dijital imzalı değildir.

## English

**If 0.6.8 is installed, use “Check for updates” in the app.** The Windows installer supports upgrading an existing installation.

- Relinking moved media no longer mixes up two takes with the same name. Other files are looked for in their own subfolders of the moved folder; a file is never given to two different sources, and a take that cannot be told apart is asked about on its own.
- When a source file of an open project is replaced at the same path, smooth playback is drawn again instead of reusing the old picture.
- On clips with a changed speed, the paused preview and the export show the same frame, and splitting a clip no longer changes the export. At 2× frames came one frame early and at 0.5× the last frame was missing; both are fixed. Splitting 24 and 60 fps footage no longer changes the export either.
- Word-by-word captions trimmed from the right no longer show the trimmed words; lengthening the clip brings them back.
- Long project names that Windows accepts can be saved.
- Files placed by hand in a project's versions folder are not deleted when old versions are cleaned up.

The Windows installer is digitally unsigned.

## Türkçe

**0.6.5 kuruluysa uygulamadaki “Güncellemeleri denetle” seçeneğini kullanabilirsiniz.** Windows kurucusu mevcut kurulumun üzerine kurulabilir.

- İngilizce arayüzde hata ve uyarı iletileri artık İngilizce. Yapay zekâ sağlayıcıları, medya, dışa aktarma, güncelleme ve kurulum hataları dahil.
- Taşınan medya yeniden bağlanabilir. Proje açılırken bulunamayan dosyaların yeni yeri sorulur; aynı klasördeki diğer eksik dosyalar adlarından kendiliğinden bulunur.
- Fotoğraflar projeyle birlikte taşınır. Proje klasörü başka bir bilgisayara taşındığında fotoğraf klipleri fotoğraftan yeniden oluşturulur. Zaman çizelgesi ve medya listesi fotoğrafın kendi adını gösterir.
- Birbirine değen iki klipte sağ kırpma tutamağı artık doğru klibi kırpıyor; önceden sınırın birkaç piksel solunda sonraki klip yakalanabiliyordu.
- Geri al ve yinele seçili klibi korur.

Windows kurucusu dijital imzalı değildir.

## English

**If 0.6.5 is installed, use “Check for updates” in the app.** The Windows installer supports upgrading an existing installation.

- Error and warning messages appear in English in the English interface, including AI provider, media, export, update and installation errors.
- Moved media can be relinked. When a project opens, you are asked where missing files are now; other missing files in the same folder are found by name.
- Photos move with the project. When a project folder moves to another computer, photo clips are rebuilt from the photo, and the timeline and media list show the photo's own name.
- On two touching clips, the right trim handle now trims the correct clip; previously the next clip could be grabbed a few pixels before the edge.
- Undo and redo keep the selected clip.

The Windows installer is digitally unsigned.

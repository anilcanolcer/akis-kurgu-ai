## Türkçe

**0.6.18 kuruluysa uygulamadaki “Güncellemeleri denetle” seçeneğini kullanabilirsiniz.** Windows kurucusu mevcut kurulumun üzerine kurulabilir.

- Dışa aktarılacak dosya başka bir programda açıksa (örneğin son videoyu gösteren bir oynatıcıda) program kısa bir süre bekler. Dosya serbest kalmazsa bunu açıkça söyler: “Hedef dosya başka bir programda açık… O programı kapatıp yeniden deneyin.” Önceden gizli geçici dosyanın adıyla “Erişim engellendi” yazıyor ve antivirüs ayarlarını öneriyordu. Eski dosya ve yarım dosya konusunda davranış aynı: eski video yerinde kalır, yarım dosya bırakılmaz.
- Proje açılamadığında mesaj artık nedeni söyler:
  - Dosya bozuk ya da yarım kalmışsa satır ve sütunuyla belirtilir.
  - Proje programın daha yeni bir sürümüyle kaydedilmişse güncelleme yapmanız istenir.
  - Dosya bir Akış Kurgu projesi değilse bu söylenir.
  - Kurgu bölümü bozulmuşsa bu belirtilir.

  Önceden bu durumlarda İngilizce ya da Python'a ait teknik metinler görünüyordu. Hangi durumda olursa olsun açık olan proje korunur.

Bu sürüm, temel akışların gerçek Windows arayüzünde ve paketlenmiş programda düğmelere basılarak denendiği bir denetimle hazırlandı.

[Denetim raporu](https://github.com/anilcanolcer/akis-kurgu-ai/blob/v0.6.19/docs/toplu-denetim-0.6.19.md)

Windows kurucusu dijital imzalı değildir.

## English

**If 0.6.18 is installed, use “Check for updates” in the app.** The Windows installer supports upgrading an existing installation.

- If the export target is open in another program (a player showing the last export, for example), the app waits briefly. If the file stays open, it now says so: “The target file is open in another program… Close that program and try again.” It used to show “Access denied” on a hidden temporary file and suggest antivirus settings. As before, the old video stays in place and no partial file is left behind.
- When a project cannot be opened, the message now gives the reason:
  - a damaged or cut-off file, with the line and column;
  - a project saved by a newer version, with a request to update;
  - a file that is not an Akış Kurgu project;
  - a damaged edit inside the file.

  These used to show English or technical Python text. The project that is open stays as it was.

This release comes from an audit in which the main flows were tried by pressing the buttons of the real Windows interface, in both the editor and the packaged program.

[Audit report (Turkish)](https://github.com/anilcanolcer/akis-kurgu-ai/blob/v0.6.19/docs/toplu-denetim-0.6.19.md)

The Windows installer is digitally unsigned.

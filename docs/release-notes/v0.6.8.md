## Türkçe

**0.6.7 kuruluysa uygulamadaki “Güncellemeleri denetle” seçeneğini kullanabilirsiniz.** Windows kurucusu mevcut kurulumun üzerine kurulabilir.

- Hızlı dışa aktarma yalnızca MP4'e olduğu gibi kopyalanabilen videolarda önerilir. ProRes ya da PCM sesli kamera MOV dosyalarında artık önerilmez; önceden seçildiğinde işlem hata veriyordu. Bu dosyalar olağan dışa aktarmayla çıkar.
- Windows kullanıcı adında ya da geçici klasör yolunda tek tırnak (’) olduğunda hızlı dışa aktarma, kelime kelime altyazılı dışa aktarma ve uzun kurguların parçalı dışa aktarması artık çalışır.
- FCPXML dışa aktarımı ses dosyalarını doğru tanımlar: tek kanallı bir WAV görüntüsüz ve tek kanallı yazılır; MP3 kapak resmi görüntü sayılmaz. Videoların kanal sayısı da dosyadan okunur.

Windows kurucusu dijital imzalı değildir.

## English

**If 0.6.7 is installed, use “Check for updates” in the app.** The Windows installer supports upgrading an existing installation.

- Fast export is offered only for videos that can be copied into an MP4 as they are. Camera MOV files with ProRes or PCM sound no longer get the offer, which previously failed once chosen; they use the normal export.
- Fast export, word-by-word caption exports and chunked exports of long edits now work when the Windows user name or the temporary folder path contains a single quote.
- FCPXML exports describe sound files correctly: a mono WAV is written as sound-only with one channel, and an MP3's cover art is not treated as video. Video files also get their real channel count.

The Windows installer is digitally unsigned.
